# 开发日志 — 5月27日

## 每个怪物独特 AI

重写 IntentResolver 为全部 29 种敌人设计独特 AI：

- **邪教徒**：60% 攻击 / 40% Buff — 入门教学，介绍 Buff 机制
- **斥候**：80% 攻击，低 HP — 快攻型，优先击杀
- **守卫**：T1 架盾，50% 防御 — 坦克型，克制纯攻击流
- **萨满**：给全体 Buff — 辅助型，必须优先处理
- **侍僧**：极低 HP，高频 Buff — 最优先击杀目标
- **蛮兵**：每 3 回合 +3 力量，75% 重击 — 需要算好格挡时机
- **剑客**：每 4 回合暴击 — 可预测的爆发
- **古代机械**：2 回合蓄力 → 毁灭打击 — 明显的出招预告
- **腐化之心**：5 回合循环 P1 → 3 回合循环 P2 — 终极 Boss

每个敌人都有清晰的战斗风格和策略应对方式。
