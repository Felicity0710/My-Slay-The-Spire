# 开发日志 — 6月3日

## 程序化音频系统

创建 AudioManager 全局音频管理器，使用 Godot 内置的 AudioStreamGenerator 进行程序化音频合成：

**BGM 系统**：
- 4 层音乐合成：Bass 低音 + Chord Pad 和弦 + Arpeggio 琶音 + Melody 旋律
- 使用 D 小调五声音阶和 C 弗里几亚音阶，营造暗黑奇幻氛围
- 10 个场景各有不同的 BGM 预制（主菜单、地图、普通战斗、精英、Boss、商店、事件、胜利、失败）

**SFX 系统**：
- 24 种音效，每种有不同的频率、时长和音量
- 出牌 880Hz、抽牌 660Hz、攻击命中 220Hz、受伤 180Hz、敌人死亡 300Hz 等
- 通过 AudioStreamGenerator 一次性渲染完整波形

**特点**：零外部文件依赖，完全程序化生成。注册为 autoload，BattleScene 的 UiSfxRequested 自动转发到 AudioManager.PlaySfx。
