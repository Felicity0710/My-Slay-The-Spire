# 开发日志 — 6月16日

## 角色与怪物背景透明化

用户反复反馈战斗中角色和怪物有背景框。经过多轮排查和修复：

**最终根因**：
1. EnemyCardView 是 Godot Button 子类，默认主题渲染了背景
2. TSCN 中 `PortraitBg` ColorRect 无显式颜色 → 默认白色 `Color(1,1,1,1)`
3. 选中状态（第一个敌人）有边框+阴影，形成可见的"背景框"
4. PlayerCardView 的 PortraitGlow 有蓝绿色发光

**修复方案**：
- EnemyCardView._Ready()：`Theme = null` 彻底移除 Button 默认主题
- CacheNodes()：立即设置 `_portraitBg.Color = (0,0,0,0)`
- Configure()：BgColor 始终透明，仅 hover 时有微弱光晕
- 选中状态不再有边框/阴影/缩放
- PlayerCardView.Configure()：强制 PortraitBg + PortraitGlow 透明
- PlayerPanel 覆盖为 StyleBoxEmpty
- EnemyCardView TSCN PortraitBg 最小高度 78→140px（基础尺寸翻倍）
