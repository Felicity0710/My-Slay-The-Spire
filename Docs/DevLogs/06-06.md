# 开发日志 — 6月6日

## 设置面板与篝火界面双语修复

发现 NodeSettingsOverlay 和 SettingsScene 的全部文字依赖 `LocalizationService.Get()` 查 JSON 表，但 JSON 加载不可靠。

改为全部使用直接语言判定：

```csharp
bool zh = LocalizationSettings.CurrentLanguage == GameLanguage.ZhHans;
_gearButton.Text = zh ? "⚙ 设置" : "⚙ Settings";
_titleLabel.Text = zh ? "设置" : "Settings";
_resolutionLabel.Text = zh ? "分辨率" : "Resolution";
// ... 全部 16 个标签
```

同样修复了 RestScene 的全部 15 处文本（标题、休息/锻造选项、升级面板、按钮等）。
