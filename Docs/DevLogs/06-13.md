# 开发日志 — 6月13日

## 卡牌封面个性化重绘

用户反馈封面复用率太高，每张卡看起来差不多。完全重写卡牌生成系统：

**设计系统**：
- 顶部横幅：攻击牌红色 `ATTACK`、技能牌蓝色 `SKILL`
- 中央主图标：根据首要效果选择（剑/盾/裂痕/卡牌/拳头/火花/十字/箭头）
- 次要效果：缩小的图标排列在下方（最多 3 个）
- 装饰区：攻击牌锐利斜线、技能牌流动圆点
- 底部：费用徽章（左下角）+ 装饰线

**特色区分**：
- 铁卫红底剑盾、舞者紫底双匕、法师蓝底光球
- 每张卡牌根据 `seed(card_id)` 生成不同的装饰元素排布
- 攻击牌图标略大于技能牌

77 张卡牌全部重新生成，每张独一无二。
