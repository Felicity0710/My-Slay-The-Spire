# 开发日志 — 5月29日

## 随机事件系统

EventScene 从 2 个事件扩展到 12 个，涵盖三种类型：

**正面事件**（纯收益）：
- 远古神龛：祈祷 +5 最大 HP / 献祭取遗物
- 神秘酿造：获得随机药水 / 当场喝下得力量卡牌
- 流浪治疗师：免费回复 25 HP / 花 35 金币 +8 最大 HP
- 卡牌祭坛：随机升级一张牌 / 随机转化一张牌
- 神秘宝箱：开箱得 25-50 金币 / 安全离开

**风险事件**（付出代价→丰厚回报）：
- 黑市商人：6 HP 换快斩（可能升级）
- 黑暗熔炉：12 HP 换 2 个随机遗物
- 血之仪式：18 HP 换 3 张战斗专注
- 赌场：25 金币 50% 翻倍 / 赔光

**战斗事件**（强制战斗→战利品）：
- 强盗伏击：战 3 个盗贼 → 得 40 金币
- 史莱姆坑：战 3 个瘟疫鼠 → 得随机遗物 / 逃跑 -5 HP
- 诅咒神像：直接 -10 HP 拿稀有遗物 / 战腐化守卫拿稀有遗物
