# 开发日志 — 6月4日

## BGM 音质优化

初版 BGM 使用单音正弦波，用户反馈刺耳难听。完全重写音乐合成引擎：

- 从单音改为 4 层音乐合成
- 使用真正的音乐音阶而非随机频率
- 每层有独立的节奏、音色和包络
- 场景差异化：
  - 主菜单 220Hz / 2.5s 间隔，舒缓
  - 普通战斗 262Hz / 1.2s，行进感
  - Boss 战 330Hz / 0.7s，紧迫激烈
  - 胜利 392Hz / 0.6s，昂扬
  - 失败 147Hz / 3.5s，低沉

## 本地化覆盖审计

用 Python 脚本扫描全部 344 个代码中引用的本地化 key，对比 JSON 文件发现 64 个缺失 key，逐一补全。包括战斗日志（奇巧触发、消耗、重放、保留）、地图节点（Boss、入口）、卡牌类型（攻击/技能）、商店界面、休息界面、通用按钮等。
