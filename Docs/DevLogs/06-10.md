# 开发日志 — 6月10日

## 卡牌关键词提示汉化

### 关键词提示弹窗

BattleScene 中鼠标悬停卡牌时右侧弹出的关键词说明面板，全部 8 行文本改为中英双语：

| 英文 | 中文 |
|------|------|
| Damage: reduced by enemy Block | 伤害：被敌方格挡抵消 |
| Block: prevents incoming damage | 格挡：在本回合抵挡受到的伤害 |
| Vulnerable: target takes +50% damage | 易伤：目标受到的伤害增加50% |
| Draw: draw extra cards now | 抽牌：立即抽取额外的卡牌 |
| Strength: increases attack damage | 力量：增加你的攻击伤害 |
| Energy: adds extra energy | 能量：本回合获得额外能量 |
| Heal: restore HP up to max | 回复：恢复生命值，最多至最大生命 |
| No keywords | 无关键词 |

### 其他修复

- CardView.UpdateKeywordChip: Retain→保留、Exhaust→消耗、Curious→奇巧
- CardData.CostLabel: "Cost"→"费用"
- HighlightCardDescription: 修正中文关键词高亮（发动→造成、便容→易伤等）
