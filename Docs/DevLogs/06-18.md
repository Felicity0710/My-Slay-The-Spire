## 遗物效果全面实装（上）— 战斗内

- philosopher_stone：每回合 +1 能量（敌人 +1 力量）
- cursed_key / coffee_dripper：每回合 +1 能量

- warlord_crown：每回合 +1 力量
- twisted_funnel：前 3 回合 +1 临时力量

**费用减免**：

- spellbook：首技能 -1 费
- overclock_core：每第 4 技能 0 费
- shadow_step：每第 4 牌 0 费

- hourglass：对易伤敌人 +1 伤害
- frozen_lens / poison_vial：易伤 +1 层
- blood_chalice：自残卡牌 +1 力量
- necronomicon：首张 2 费攻击打出两次
- twin_blade_badge：首张攻击 +60% 伤害
