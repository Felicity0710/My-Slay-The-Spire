# 开发日志 — 6月5日

## 本地化 JSON 编码修复

发现 LocalizationService 无法加载 JSON 文件，导致所有文本回退到英文硬编码。

**根因分析**：Python 的 `json.dump` 默认输出无 BOM 的 UTF-8，但 Godot 的 `FileAccess.GetAsText()` 在 Windows 上需要 BOM 来正确识别编码。缺少 BOM 导致文件读取失败 → `LocalizationService.LoadLanguage()` 静默返回 → 字典为空 → 所有 `Get()` 调用返回英文 fallback。

**修复方案**：
1. 重新保存为 UTF-8 BOM + CRLF + ASCII-safe 格式
2. 在 `LoadLanguage()` 中添加 `ProjectSettings.GlobalizePath` 作为备选路径
3. 添加多层文件系统回退（AppContext.BaseDirectory、GetCurrentDirectory 等）
