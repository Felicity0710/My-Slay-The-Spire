# 开发日志 — 5月25日

## Bug 修复 — JSON 解析崩溃

发现并修复了一个严重的崩溃 Bug：cards.json、enemies.json、relics.json 中包含了 `{"__comment__": "..."}` 注释对象。这些对象被 `System.Text.Json` 当作正常数据解析，导致 `CardCatalog.Load()` 抛出 `InvalidOperationException`，整个游戏崩溃。

### 症状
- 选角界面只显示一个预设
- 无法开始游戏
- 卡牌图鉴为空
- 所有返回按钮失效

### 修复
用 Python 脚本递归清理了所有 JSON 文件中的 `__comment` 键，重新验证通过。
