# 开发日志 — 6月2日

## 语言切换与中英混杂修复

### 语言按钮失效

SettingsScene 的 try-catch 块包裹了语言按钮的信号连接。当 `PopulateResolutionOptions()` 抛异常时，`_languageButton.Pressed += OnLanguagePressed` 永远不会执行，导致语言切换按钮失效。

修复：将语言按钮连接、`LanguageChanged` 订阅和 `RefreshText()` 调用移出 try-catch，确保在任何情况下都生效。

### 语言按钮 UX

语言按钮原本显示"切换到 English/中文"（暗示点击后的目标语言），改为显示当前语言名（"中文"/"English"），更直观。

### 中英混杂根因

`LocalizationService.Get()` 在中文模式下会回退到英文键值，导致部分文本显示英文。修复：移除英文回退逻辑，确保缺失翻译时使用调用者提供的中文 fallback。
