# 开发日志 — 6月7日

## 药水与遗物双语显示

### 药水系统

PotionData 新增 `NameZh` 和 `DescriptionZh` 字段，以及 `DisplayName` / `DisplayDescription` 属性。10 种药水全部内置中英双语。

更新 7 处药水显示点：
- BattleScene.Potions.cs — 药水按钮文字、提示、战斗日志
- RunStatusOverlay.cs — 状态栏药水提示
- MapScene.cs — 地图药水槽提示
- RewardScene.cs — 战后药水奖励
- ShopScene.cs — 商店药水商品

### 遗物系统

RelicData 新增 `ZhText` 内置中文表（63 个遗物全部双语），`LocalizedName` / `LocalizedDescription` 直接读取语言判定。配合 Python 生成脚本自动从 `zh_hans.json` 提取翻译。
